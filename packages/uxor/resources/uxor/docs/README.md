# UXor

Build Symfony interfaces from Twig components, forms and ready-made pages. Pick a recipe, preview it in light
and dark, and copy its source into your application with Symfony UX Toolkit. Your team owns the installed files.

## Install

**[Set up UXor with the Composer development package](packages/uxor/README.md)** to start in a new or existing
Symfony application. The guide walks you and your coding agent from installing `xormania/uxor` to rendering
a first component. The package supplies the catalog, instructions and diagnostics. Symfony UX Toolkit installs
the recipes you choose.

| What do you want to do? | Start here |
| --- | --- |
| See what UXor looks like | [View the example app](https://xormania.github.io/uxor/demo/) or [browse the recipe catalog](https://xormania.github.io/uxor/#recipes). |
| Add a component to a configured app | [Look up and render a recipe](packages/uxor/README.md#use). |
| Install the kit directly or configure the tools yourself | [Direct Toolkit installation](INSTALL.md) · [Advanced configuration](packages/uxor/OPERATIONS.md) |
| Work on UXor itself | [Contribute to the kit or package](https://github.com/xormania/uxor/blob/0.3.5/CONTRIBUTING.md). |

## Requirements

The standard Symfony setup uses Twig, Stimulus, AssetMapper and TailwindBundle's standalone compiler.
See the [kit requirements](INSTALL.md#requirements) for supported versions and extensions. Each recipe's
gallery page lists the dependencies it adds.
